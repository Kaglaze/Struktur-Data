  • Buat program untuk membalik urutan kata dalam sebuah kalimat menggunakan stack.

Input: Saya belajar struktur data

Output: data struktur belajar Saya

Kode
def reverse(teks, stak):
    kata = teks.split()
    for i in kata[::-1]:
        stak.append(i)
        kalimat = " ".join(stak)
    print("Reverse:" ,kalimat)

stak = []
teks = input("Masukkan kata: ")
reverse(teks, stak)
