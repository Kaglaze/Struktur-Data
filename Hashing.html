6.1 Hashing

Hashing adalah teknik untuk menyimpan dan mengambil data dengan bantuan hash key atau hash index. Data yang awalnya besar atau beragam akan diubah menjadi indeks tertentu melalui hash function.

Pada materi ini, pembahasan hashing meliputi:

  1. Pengertian Hashing
  2. Hash Function
  3. Hash Table
  4. Collision
  5. Open Addressing
  6. Linear Probing
  7. Quadratic Probing
  8. Close Address / Chaining
  9. Contoh implementasi sederhana menggunakan Python

Catatan ini dibuat dengan bentuk seperti notebook sebelumnya, yaitu berisi penjelasan, contoh kode, output, dan analisa singkat.

Pengertian Hashing

Hashing adalah proses mengubah sebuah data atau key menjadi nilai indeks tertentu agar data dapat disimpan dan dicari dengan cepat.

Secara sederhana, hashing digunakan agar program tidak perlu mencari data satu per satu dari awal sampai akhir. Jika hash function yang digunakan baik, proses seperti insert, search, dan delete dapat berjalan lebih cepat.

Contoh penggunaan hashing dalam kehidupan nyata:

  1. Menyimpan data pada dictionary.
  2. Mengecek data yang sudah pernah muncul.
  3. Menyimpan password dalam bentuk hash.
  4. Membuat indeks pada database.
  5. Menghitung frekuensi kemunculan data.

Dalam Python, konsep hashing sering terlihat pada penggunaan dict dan set.

Komponen Utama Hashing

Dalam hashing terdapat tiga komponen utama:

  1. Key
    Key adalah nilai yang dimasukkan ke dalam hash function. Contohnya angka 54, 26, atau teks seperti "nama".

  2. Hash Function
    Hash function adalah fungsi yang mengubah key menjadi index.

  3. Hash Table
    Hash table adalah tempat penyimpanan data. Bentuk sederhananya dapat berupa list atau array.

Contoh rumus hash function yang sederhana:

index = key % ukuran_tabel

Pada PPT, rumus yang digunakan dituliskan sebagai:

Hash Value = Key mod (n + 1)

Jika ukuran tabel adalah 11, maka hash value dapat dihitung dengan:

index = key % 11

# Contoh hash function sederhana

ukuran_tabel = 11

def hash_function(key):
    return key % ukuran_tabel

Fungsi tersebut menerima sebuah key, kemudian mengembalikan hasil sisa bagi dari key terhadap ukuran tabel.

Contoh:

Artinya, data 54 akan ditempatkan pada indeks ke-10.

Hash function yang baik sebaiknya mampu menyebarkan data secara merata agar tidak terlalu banyak data yang masuk ke indeks yang sama.

A. Collision pada Hashing

Pengertian Collision

Collision terjadi ketika dua atau lebih data menghasilkan index hash yang sama.

Misalnya:

77 % 11 = 0
44 % 11 = 0
55 % 11 = 0

Ketiga data tersebut sama-sama masuk ke indeks 0. Karena satu slot tidak bisa langsung menampung beberapa data jika menggunakan bentuk tabel biasa, maka diperlukan teknik penanganan collision.

Beberapa cara menangani collision:

  1. Open Addressing
  2. Linear Probing
  3. Quadratic Probing
  4. Close Address / Chaining
Kode
# Contoh melihat collision

ukuran_tabel = 11
data = [54, 26, 93, 17, 77, 31, 44, 55, 20]

hasil_hash = {}

for angka in data:
    index = angka % ukuran_tabel

    if index not in hasil_hash:
        hasil_hash[index] = []

    hasil_hash[index].append(angka)

for index in hasil_hash:
    print("Index", index, ":", hasil_hash[index])

Index 4 : [26]
Index 5 : [93]
Index 6 : [17]
Index 0 : [77, 44, 55]
Index 9 : [31, 20]

Analisa Collision

Dari output kode, dapat terlihat bahwa beberapa indeks dapat memiliki lebih dari satu data.

Contoh:

Index 0 : [77, 44, 55]

Artinya, 77, 44, dan 55 mengalami collision karena memiliki index hash yang sama.

Collision tidak berarti program salah, tetapi collision harus ditangani dengan metode tertentu agar data tetap dapat disimpan dan dicari kembali.

B. Open Addressing

Pengertian Open Addressing

Open Addressing adalah metode penanganan collision dengan cara mencari slot kosong lain di dalam hash table yang sama.

Jika index utama sudah terisi, program tidak membuat list tambahan, tetapi mencari posisi kosong lain.

Ciri-ciri Open Addressing:

  1. Semua data tetap disimpan di dalam satu hash table.
  2. Jika terjadi collision, program melakukan pencarian slot kosong.
  3. Hash table dapat penuh jika semua slot sudah terisi.
  4. Proses pencarian slot disebut probing.

Jenis probing yang dibahas pada materi ini:

  1. Linear Probing
  2. Quadratic Probing

C. Linear Probing

Pengertian Linear Probing

Linear Probing adalah teknik mencari slot kosong dengan cara bergerak satu per satu secara berurutan.

Jika index awal penuh, maka program mengecek:

index + 1
index + 2
index + 3

Jika sudah sampai akhir tabel, pengecekan dapat kembali ke awal menggunakan operator modulo.

Rumus sederhana:

posisi = (index_awal + i) % ukuran_tabel

Keterangan:

  1. index_awal adalah hasil dari hash function.
  2. i adalah jumlah langkah percobaan.
  3. % ukuran_tabel digunakan agar index tidak keluar dari batas list.
Kode
# Linear Probing

ukuran_tabel = 11
table = [None] * ukuran_tabel
data = [54, 26, 93, 17, 77, 31, 44, 55, 20, 25]

def hash_function(key):
    return key % ukuran_tabel

def insert_linear(key):
    index_awal = hash_function(key)

    print("Memasukkan:", key)
    print("Index awal:", index_awal)

    for i in range(ukuran_tabel):
        posisi = (index_awal + i) % ukuran_tabel

        print("Cek posisi:", posisi)

        if table[posisi] is None:
            table[posisi] = key
            print("Data masuk ke posisi:", posisi)
            print("Tabel sekarang:", table)
            print()
            return

    print("Tabel penuh, data gagal dimasukkan")
    print()

for angka in data:
    insert_linear(angka)

D. Quadratic Probing

Pengertian Quadratic Probing

Quadratic Probing adalah teknik menangani collision dengan pola lompatan kuadrat.

Jika index awal penuh, maka program mengecek:

index + 1²
index + 2²
index + 3²
index + 4²

Rumus sederhana:

posisi = (index_awal + i * i) % ukuran_tabel

Quadratic Probing digunakan untuk mengurangi penumpukan yang sering terjadi pada Linear Probing.

Kode
# Quadratic Probing

ukuran_tabel = 11
table = [None] * ukuran_tabel
data = [54, 26, 93, 17, 77, 31, 44, 55, 20]

def hash_function(key):
    return key % ukuran_tabel

def insert_quadratic(key):
    index_awal = hash_function(key)

    print("Memasukkan:", key)
    print("Index awal:", index_awal)

    for i in range(ukuran_tabel):
        posisi = (index_awal + i * i) % ukuran_tabel

        print("Cek posisi:", posisi)

        if table[posisi] is None:
            table[posisi] = key
            print("Data masuk ke posisi:", posisi)
            print("Tabel sekarang:", table)
            print()
            return

    print("Tabel penuh, data gagal dimasukkan")
    print()

for angka in data:

E. Close Address / Chaining

Pengertian Chaining

Chaining adalah teknik menangani collision dengan cara membuat setiap slot pada hash table berisi list.

Jika beberapa data masuk ke index yang sama, data tersebut tetap disimpan pada index tersebut, tetapi ditambahkan ke dalam list.

Contoh:

Index 0 : [77, 44, 55]

Artinya data 77, 44, dan 55 berada pada slot yang sama, tetapi disimpan dalam bentuk rantai atau chain.

Keunggulan Chaining:

  1. Lebih fleksibel ketika banyak collision.
  2. Tabel tidak langsung gagal hanya karena satu index sudah terisi.
  3. Implementasinya mudah dipahami menggunakan list di dalam list.
Kode
# Chaining / Close Address

ukuran_tabel = 11
table = [[] for i in range(ukuran_tabel)]
data = [54, 26, 93, 17, 77, 31, 44, 55, 20]

def hash_function(key):
    return key % ukuran_tabel

def insert_chaining(key):
    index = hash_function(key)
    table[index].append(key)
    print("Data", key, "masuk ke index", index)
    print("Tabel sekarang:", table)
    print()

for angka in data:
    insert_chaining(angka)

F. Search Data pada Hash Table dengan Chaining

Setelah data dimasukkan ke hash table, data juga harus dapat dicari kembali.

Pada Chaining, proses pencarian dilakukan dengan langkah berikut:

  1. Hitung index menggunakan hash function.
  2. Masuk ke list pada index tersebut.
  3. Periksa apakah data ada di dalam list.
  4. Jika ada, data ditemukan.
  5. Jika tidak ada, data tidak ditemukan.
Kode
# Search data pada hash table chaining

ukuran_tabel = 11
table = [[] for i in range(ukuran_tabel)]
data = [54, 26, 93, 17, 77, 31, 44, 55, 20]

def hash_function(key):
    return key % ukuran_tabel

def insert_chaining(key):
    index = hash_function(key)
    table[index].append(key)

def search_chaining(key):
    index = hash_function(key)

    print("Mencari data:", key)
    print("Index hash:", index)
    print("Isi slot:", table[index])

    if key in table[index]:
        print("Status: data ditemukan")
    else:
        print("Status: data tidak ditemukan")

    print()

for angka in data:
    insert_chaining(angka)

print("Hash table:", table)
print()

Analisa Search pada Chaining

Pada pencarian data 44, program menghitung index terlebih dahulu:

44 % 11 = 0

Kemudian program memeriksa isi list pada index 0.

Karena 44 ada di dalam list tersebut, maka data ditemukan.

Pada pencarian data 99, program juga menghitung index terlebih dahulu. Namun, karena 99 tidak ada di slot hasil hash-nya, maka data dinyatakan tidak ditemukan.

G. Perbandingan Linear Probing, Quadratic Probing, dan Chaining

Metode Cara Menangani Collision Kelebihan Kekurangan
Linear Probing Mencari slot kosong berikutnya secara berurutan Mudah dibuat dan dipahami Dapat menyebabkan penumpukan data
Quadratic Probing Mencari slot kosong dengan pola kuadrat Mengurangi penumpukan berurutan Tidak selalu mengecek semua slot pada kondisi tertentu
Chaining Menyimpan beberapa data dalam list pada index yang sama Fleksibel saat banyak collision Membutuhkan list tambahan pada setiap slot

Dari ketiga metode tersebut, pemilihan metode tergantung pada kebutuhan program dan kondisi data.

J. Kesimpulan

Hashing adalah teknik penyimpanan dan pencarian data dengan menggunakan hash function untuk menentukan index penyimpanan.

Poin penting dari materi hashing:

  1. Hashing digunakan untuk mempercepat proses pencarian, penyisipan, dan penghapusan data.
  2. Hash function mengubah key menjadi index pada hash table.
  3. Collision terjadi jika beberapa key menghasilkan index yang sama.
  4. Collision dapat ditangani dengan Open Addressing atau Chaining.
  5. Linear Probing mencari slot kosong secara berurutan.
  6. Quadratic Probing mencari slot kosong dengan pola kuadrat.
  7. Chaining menyimpan beberapa data pada index yang sama menggunakan list.
  8. Dalam Python, konsep hashing dapat ditemukan pada dict dan set.

Dengan memahami hashing, kita dapat membuat struktur data yang lebih efisien untuk menyimpan dan mencari data.

Analisa Mid Square Function

  • Mid Square Function digunakan untuk menentukan index hash.
  • Data dikuadratkan terlebih dahulu.
  • Angka tengah dari hasil kuadrat digunakan sebagai index.
  • Metode ini membantu penyebaran data agar lebih merata.
Kode
# 1. Kasus Chaining (Close Adrress)
# - insert
# - cari --> ketemu
# - delete
# - update

print("=== CHAINING ===")

def tampil(tabel):
  print(tabel)

def insertChain(tabel, angka):
  index = midSquare(angka)
  tabel[index].append(angka)

def cariChain(tabel, angka):
  index = midSquare(angka)

  if angka in tabel[index]:
    print(angka, "ditemukan")
  else:
    print(angka, "tidak ditemukan")

def hapusChain(tabel, angka):
  index = midSquare(angka)

  if angka in tabel[index]:
    tabel[index].remove(angka)
    print(angka, "berhasil dihapus")
  else:
    print(angka, "tidak ditemukan")

def updateChain(tabel, lama, baru):
  index = midSquare(lama)

  if lama in tabel[index]:
    tabel[index].remove(lama)
    insertChain(tabel, baru)
    print(lama, "diubah menjadi", baru)
  else:
    print(lama, "tidak ditemukan")

chain = [[] for i in range(ukuran)]

for angka in data:
  insertChain(chain, angka)

print("Setelah insert:")
tampil(chain)

print("Cari 34:")
cariChain(chain, 34)

print("Hapus 34:")
hapusChain(chain, 34)
tampil(chain)

print("Update 45 menjadi 99:")
updateChain(chain, 45, 99)
tampil(chain)

print("Insert saat index sudah berisi:")
insertChain(chain, 90)
tampil(chain)

print("==LINEAR PROBING==")

def insertLinear(tabel, angka):
  idx = midSquare(angka)

  for i in range(ukuran):
    posisi = (idx + i) % ukuran

    if tabel[posisi] is None or tabel[posisi] == hapus:
      tabel[posisi] = angka
      return

  print("Tabel penuh, insert", angka, "gagal")

def cariLinear(tabel, angka):
  idx = midSquare(angka)

  for i in range(ukuran):
    posisi = (idx + i) % ukuran

    if tabel[posisi] is None:
      print(angka, "tidak ditemukan")
      return -1

    if tabel[posisi] == angka:
      print(angka, "ditemukan")
      return posisi

  print(angka, "tidak ditemukan")
  return -1

def hapusLinear(tabel, angka):
  posisi = cariLinear(tabel, angka)

  if posisi != -1:
    tabel[posisi] = hapus
    print(angka, "berhasil dihapus")

def updateLinear(tabel, lama, baru):
  posisi = cariLinear(tabel, lama)

  if posisi != -1:
    tabel[posisi] = hapus
    insertLinear(tabel, baru)
    print(lama, "diubah menjadi", baru)
