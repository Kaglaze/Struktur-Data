5.1 Searching

Data tidak hanya sekadar diinput, tetapi data juga sering perlu dicari kembali. Proses pencarian data disebut searching. Searching digunakan untuk menemukan apakah suatu data ada di dalam list atau array, serta mengetahui posisi atau indeks dari data tersebut.

Pada materi ini, algoritma searching yang dibahas hanya:

  1. Linear Search pada data tidak terurut
  2. Linear Search pada data terurut
  3. Binary Search

Pengertian Searching

Searching adalah proses untuk mencari suatu nilai tertentu di dalam kumpulan data. Kumpulan data tersebut dapat berupa list, array, tabel, atau struktur data lainnya.

Contoh sederhana:

data = [1, 7, 11, 23, 39, 43, 56]
cari = 23

Dari contoh tersebut, program akan mencari apakah angka 23 ada di dalam list. Jika ada, program dapat menampilkan posisi atau indeks dari data tersebut.

A. Linear Search pada Data Tidak Terurut

Pengertian Linear Search

Linear Search atau Sequential Search adalah algoritma pencarian yang dilakukan dengan cara mengecek data satu per satu dari awal sampai akhir.

Linear Search dapat digunakan pada:

  1. Data yang belum terurut
  2. Data yang sudah terurut
  3. Data dengan jumlah kecil

Pada data tidak terurut, program tidak bisa menebak posisi data yang dicari. Oleh karena itu, program harus memeriksa elemen dari indeks pertama sampai data ditemukan atau sampai semua data selesai dicek.

Cara Kerja Linear Search Data Tidak Terurut

Misalnya terdapat list:

data = [43, 11, 56, 1, 39, 7, 23]
cari = 23

Langkah pencarian:

  1. Mulai dari indeks ke-0.
  2. Bandingkan data pada indeks tersebut dengan nilai yang dicari.
  3. Jika sama, pencarian berhenti.
  4. Jika tidak sama, lanjut ke indeks berikutnya.
  5. Jika sampai akhir tidak ditemukan, berarti data tidak ada di dalam list.

Pada data tidak terurut, pencarian tidak boleh berhenti hanya karena nilai yang dicek lebih besar atau lebih kecil dari nilai yang dicari, karena susunan datanya masih acak.

Kode
# Linear Search pada data tidak terurut

search = 23
myList = [43, 11, 56, 1, 39, 7, 23]

found = False
index = 0
looping = 0

while index < len(myList) and not found:
    looping += 1
    print("Looping ke-", looping)
    print("Cek indeks:", index)
    print("Nilai yang dicek:", myList[index])

    if myList[index] == search:
        found = True
        print("Status: data ditemukan")
    else:
        print("Status: data belum ditemukan")
        index += 1

    print()

if found:
    print("Hasil akhir: data", search, "ditemukan pada indeks", index)
    print("Jumlah looping:", looping)
else:
    print("Hasil akhir: data", search, "tidak ditemukan")
    print("Jumlah looping:", looping)

Jika data ditemukan, maka found berubah menjadi True dan perulangan berhenti.

B. Linear Search pada Data Terurut

Pengertian Linear Search Data Terurut

Linear Search juga dapat digunakan pada data yang sudah terurut. Cara dasarnya tetap sama, yaitu mengecek data satu per satu dari awal ke akhir.

Namun, pada data yang sudah terurut secara ascending, pencarian dapat dihentikan lebih cepat jika nilai yang sedang dicek sudah lebih besar daripada nilai yang dicari.

Contoh:

data = [1, 7, 11, 23, 39, 43, 56]
cari = 25

Jika program sudah mengecek angka 39, maka pencarian bisa dihentikan karena 39 lebih besar dari 25. Karena data sudah terurut, nilai setelah 39 pasti lebih besar lagi.

First Index, Last Index, dan Len

Contoh list:

data = [1, 7, 11, 23, 39, 43, 56]

Keterangan:

  1. First index = 0
  2. Last index = 6
  3. Len atau panjang data = 7

Pada Python, indeks dimulai dari 0, sehingga indeks terakhir adalah:

len(data) - 1
Kode
# Linear Search pada data terurut

search = 25
myList = [1, 7, 11, 23, 39, 43, 56]

found = False
index = 0
looping = 0

while index < len(myList) and not found:
    looping += 1
    print("Looping ke-", looping)
    print("Cek indeks:", index)
    print("Nilai yang dicek:", myList[index])

    if myList[index] == search:
        found = True
        print("Status: data ditemukan")
    elif myList[index] > search:
        print("Status: pencarian dihentikan")
        print("Alasan:", myList[index], "lebih besar dari", search)
        break
    else:
        print("Status: data belum ditemukan, lanjut ke indeks berikutnya")
        index += 1

    print()

if found:
    print("Hasil akhir: data", search, "ditemukan pada indeks", index)
    print("Jumlah looping:", looping)
else:
    print("Hasil akhir: data", search, "tidak ditemukan")
    print("Jumlah looping:", looping)

Perbedaan Linear Search Tidak Terurut dan Terurut

Pada data tidak terurut, program harus terus mengecek sampai data ditemukan atau sampai data terakhir.

Pada data terurut, program bisa berhenti lebih cepat jika nilai yang sedang dicek sudah melewati nilai yang dicari.

Contoh:

  • Target = 25
  • Data yang dicek = 39
  • Karena 39 > 25, maka pencarian bisa dihentikan.

C. Binary Search

Pengertian Binary Search

Binary Search adalah algoritma pencarian yang dilakukan dengan cara membagi area pencarian menjadi dua bagian.

Binary Search bekerja dengan mengecek data pada bagian tengah terlebih dahulu. Jika nilai tengah sama dengan data yang dicari, maka data ditemukan. Jika nilai yang dicari lebih kecil dari nilai tengah, pencarian dilanjutkan ke bagian kiri. Jika nilai yang dicari lebih besar dari nilai tengah, pencarian dilanjutkan ke bagian kanan.

Syarat utama Binary Search adalah data harus sudah terurut.

Cara Kerja Binary Search

Misalnya terdapat data:

data = [1, 7, 11, 23, 39, 43, 56]
cari = 39

Langkah Binary Search:

  1. Tentukan indeks awal dengan nama first.
  2. Tentukan indeks akhir dengan nama last.
  3. Cari indeks tengah dengan rumus:
middle = (first + last) // 2
  1. Bandingkan data pada indeks tengah dengan nilai yang dicari.
  2. Jika sama, data ditemukan.
  3. Jika nilai yang dicari lebih kecil, geser batas akhir ke kiri.
  4. Jika nilai yang dicari lebih besar, geser batas awal ke kanan.
Kode
# Binary Search

search = 39
myList = [1, 7, 11, 23, 39, 43, 56]

first = 0
last = len(myList) - 1
found = False
looping = 0

while first <= last and not found:
    looping += 1
    middle = (first + last) // 2

    print("Looping ke-", looping)
    print("First index:", first)
    print("Last index:", last)
    print("Middle index:", middle)
    print("Nilai tengah:", myList[middle])

    if myList[middle] == search:
        found = True
        print("Status: data ditemukan")
    else:
        if search < myList[middle]:
            print("Status: cari di bagian kiri")
            last = middle - 1
        else:
            print("Status: cari di bagian kanan")
            first = middle + 1

    print()

if found:
    print("Hasil akhir: data", search, "ditemukan pada indeks", middle)
    print("Jumlah looping:", looping)
else:
    print("Hasil akhir: data", search, "tidak ditemukan")
    print("Jumlah looping:", looping)

Binary Search Versi Fungsi

Selain ditulis langsung, Binary Search juga dapat dibuat dalam bentuk fungsi. Dengan fungsi, kode dapat digunakan berulang kali untuk mencari data yang berbeda.

Kode
# Binary Search versi fungsi

def binarySearch(alist, item):
    first = 0
    last = len(alist) - 1
    found = False

    while first <= last and not found:
        midpoint = (first + last) // 2

        if alist[midpoint] == item:
            found = True
        else:
            if item < alist[midpoint]:
                last = midpoint - 1
            else:
                first = midpoint + 1

    return found

testlist = [0, 1, 2, 8, 13, 17, 19, 32, 42]

print(binarySearch(testlist, 3))

D. Perbandingan Linear Search dan Binary Search

Syarat data Tidak harus terurut Harus terurut agar bisa berhenti lebih cepat Harus terurut
Cocok untuk Data kecil atau acak Data terurut dengan jumlah kecil sampai sedang Data terurut dengan jumlah besar

# Perbandingan jumlah looping sederhana

data_tidak_terurut = [43, 11, 56, 1, 39, 7, 23]

E. Kesimpulan

Searching adalah proses mencari data tertentu di dalam kumpulan data. Pada materi ini, algoritma searching yang dibahas adalah Linear Search dan Binary Search.

Linear Search pada data tidak terurut dilakukan dengan mengecek data satu per satu dari awal sampai akhir. Algoritma ini mudah dipahami dan dapat digunakan pada data acak.

Linear Search pada data terurut tetap mengecek data satu per satu, tetapi dapat dihentikan lebih cepat jika nilai yang sedang dicek sudah lebih besar daripada nilai yang dicari.

Binary Search adalah algoritma pencarian yang lebih cepat karena membagi area pencarian menjadi dua bagian. Namun, Binary Search hanya bisa digunakan jika data sudah terurut.

Jadi, jika data masih acak dan jumlahnya sedikit, Linear Search dapat digunakan. Jika data sudah terurut dan jumlahnya besar, Binary Search lebih efisien.
