8.1 Tree

Tree adalah struktur data non-linear yang menyimpan data dalam bentuk hubungan bertingkat.
Tree terdiri dari node yang saling terhubung menggunakan edge.

Pengertian Tree

Tree adalah struktur data yang bentuknya menyerupai pohon, tetapi posisi akarnya berada di bagian atas dan daun berada di bagian bawah.

Dalam struktur data tree:

  • Data disimpan dalam bentuk node.
  • Hubungan antar node disebut edge.
  • Node paling atas disebut root.
  • Node yang tidak memiliki anak disebut leaf.

Tree berbeda dengan list, stack, dan queue karena data pada tree tidak berjalan satu arah saja. Tree memiliki cabang sehingga cocok digunakan untuk menggambarkan hubungan hierarki.

Contoh penggunaan tree:

  1. Struktur folder pada komputer
  2. Struktur organisasi
  3. Silsilah keluarga
  4. Parse tree pada ekspresi matematika
  5. Binary Search Tree untuk pencarian data

Istilah Dasar pada Tree

Beberapa istilah penting pada tree adalah sebagai berikut.

  1. Node
    Node adalah bagian utama dari tree yang menyimpan data.

  2. Edge
    Edge adalah garis penghubung antara satu node dengan node lainnya.

  3. Root
    Root adalah node paling atas dan tidak memiliki parent.

  4. Parent
    Parent adalah node yang memiliki hubungan ke node di bawahnya.

  5. Child
    Child adalah node anak yang berada di bawah parent.

  6. Sibling
    Sibling adalah node-node yang memiliki parent yang sama.

  7. Path
    Path adalah urutan node yang dilewati dari satu node ke node lainnya.

  8. Subtree
    Subtree adalah bagian kecil dari tree yang terdiri dari sebuah node dan seluruh turunannya.

  9. Leaf Node
    Leaf node adalah node yang tidak memiliki child.

  10. Level
    Level adalah jumlah edge dari root menuju node tertentu. Root berada pada level 0.

  11. Height
    Height adalah tinggi tree, yaitu level paling jauh dari root menuju leaf.

Contoh Bentuk Tree

Misalnya terdapat tree seperti berikut.

        A
      /   \
     B     C
          / \
         D   E

Keterangan:

  • A adalah root.
  • B dan C adalah child dari A.
  • D dan E adalah child dari C.
  • B, D, dan E adalah leaf node.
  • Path dari A ke E adalah A -> C -> E.
  • Height tree tersebut adalah 2, karena jalur terpanjang memiliki 2 edge.

A. Binary Tree

Pengertian Binary Tree

Binary Tree adalah tree yang setiap node-nya hanya boleh memiliki maksimal dua child.

Dua child tersebut biasanya disebut:

  1. Left Child
  2. Right Child

Contoh binary tree:

        A
      /   \
     B     C
          / \
         D   E

Pada contoh tersebut:

  • A memiliki left child B dan right child C.
  • C memiliki left child D dan right child E.
  • B, D, dan E tidak memiliki child.
Kode
# Implementasi Binary Tree sederhana

class BinaryTree:
    def __init__(self, rootObj):
        self.key = rootObj
        self.leftChild = None
        self.rightChild = None

    def insertLeft(self, newNode):
        if self.leftChild == None:
            self.leftChild = BinaryTree(newNode)
        else:
            temp = BinaryTree(newNode)
            temp.leftChild = self.leftChild
            self.leftChild = temp

    def insertRight(self, newNode):
        if self.rightChild == None:
            self.rightChild = BinaryTree(newNode)
        else:
            temp = BinaryTree(newNode)
            temp.rightChild = self.rightChild
            self.rightChild = temp

    def getLeftChild(self):
        return self.leftChild

    def getRightChild(self):
        return self.rightChild

    def setRootVal(self, obj):
        self.key = obj

    def getRootVal(self):
        return self.key

    def height(self):
        if self.leftChild == None and self.rightChild == None:
            return 0

        left_height = 0
        right_height = 0

        if self.leftChild != None:
            left_height = self.leftChild.height() + 1

        if self.rightChild != None:
            right_height = self.rightChild.height() + 1

        if left_height > right_height:
            return left_height
        else:
            return right_height

    def show(self, level=0):
        print("  " * level + str(self.key))
        if self.leftChild != None:
            self.leftChild.show(level + 1)
        if self.rightChild != None:
            self.rightChild.show(level + 1)

print("Left child dari root:", r.getLeftChild().getRootVal())

B. Tree Traversal

Pengertian Tree Traversal

Tree Traversal adalah proses mengunjungi semua node pada tree dengan urutan tertentu.

Traversal yang umum digunakan pada binary tree adalah:

  1. Preorder
    Urutannya: Root -> Left -> Right

  2. Inorder
    Urutannya: Left -> Root -> Right

  3. Postorder
    Urutannya: Left -> Right -> Root

Misalnya terdapat tree:

        A
      /   \
     B     C
          / \
         D   E

Maka hasil traversalnya:

  • Preorder: A B C D E
  • Inorder: B A D C E
  • Postorder: B D E C A
Kode
# Tree Traversal pada Binary Tree

def preorder(tree):
    if tree != None:
        print(tree.getRootVal(), end=' ')
        preorder(tree.getLeftChild())
        preorder(tree.getRightChild())


def inorder(tree):
    if tree != None:
        inorder(tree.getLeftChild())
        print(tree.getRootVal(), end=' ')
        inorder(tree.getRightChild())


def postorder(tree):
    if tree != None:
        postorder(tree.getLeftChild())
        postorder(tree.getRightChild())
        print(tree.getRootVal(), end=' ')

Penjelasan Tree Traversal

Pada preorder, root dikunjungi terlebih dahulu. Setelah itu program masuk ke subtree kiri, lalu subtree kanan.

Pada inorder, subtree kiri dikunjungi terlebih dahulu. Setelah itu root, lalu subtree kanan.

Pada postorder, subtree kiri dan subtree kanan dikunjungi terlebih dahulu. Root dikunjungi paling akhir.

Traversal sering digunakan untuk:

  1. Menampilkan semua data di dalam tree
  2. Mengevaluasi ekspresi matematika
  3. Menyalin struktur tree
  4. Menghapus tree dari node paling bawah

C. Parse Tree

Pengertian Parse Tree

Parse Tree adalah tree yang digunakan untuk menggambarkan struktur dari sebuah ekspresi.

Contoh ekspresi:

( ( 10 * 5 ) * ( ( 5 + 6 ) / 9 ) )

Ekspresi tersebut dapat dibentuk menjadi tree. Operator seperti +, -, *, dan / menjadi node internal, sedangkan angka menjadi leaf node.

Parse tree berguna untuk memahami urutan perhitungan pada ekspresi matematika.

Kode
# Parse Tree sederhana

class Stack:
    def __init__(self):
        self.items = []

    def push(self, item):
        self.items.append(item)

    def pop(self):
        return self.items.pop()

    def isEmpty(self):
        return self.items == []


def buildParseTree(fpexp):
    fplist = fpexp.split()
    pStack = Stack()
    eTree = BinaryTree('')
    pStack.push(eTree)
    currentTree = eTree

    for i in fplist:
        if i == '(':
            currentTree.insertLeft('')
            pStack.push(currentTree)
            currentTree = currentTree.getLeftChild()

        elif i not in ['+', '-', '*', '/', ')']:
            currentTree.setRootVal(int(i))
            parent = pStack.pop()
            currentTree = parent

        elif i in ['+', '-', '*', '/']:
            currentTree.setRootVal(i)
            currentTree.insertRight('')
            pStack.push(currentTree)
            currentTree = currentTree.getRightChild()

        elif i == ')':
            currentTree = pStack.pop()

    return eTree


def hitung(angka1, operator, angka2):
    if operator == '+':
        return angka1 + angka2
    elif operator == '-':
        return angka1 - angka2
    elif operator == '*':
        return angka1 * angka2
    elif operator == '/':
        return angka1 / angka2


def postordereval(tree):
    if tree != None:
        kiri = postordereval(tree.getLeftChild())
        kanan = postordereval(tree.getRightChild())

        if kiri != None and kanan != None:
            return hitung(kiri, tree.getRootVal(), kanan)
        else:
            return tree.getRootVal()


pt = buildParseTree("( ( 10 * 5 ) * ( ( 5 + 6 ) / 9 ) )")

print("Preorder  :", end=' ')
preorder(pt)
print()

print("Inorder   :", end=' ')
inorder(pt)
print()

print("Postorder :", end=' ')
postorder(pt)
print()

print("Hasil evaluasi:", postordereval(pt))

Inorder   : 10 * 5 * 5 + 6 / 9 
Postorder : 10 5 * 5 6 + 9 / *

Jika bertemu kurung buka, program membuat cabang kiri baru karena ekspresi baru akan dimulai.

Jika bertemu operator, operator tersebut disimpan sebagai root dari subtree saat ini.

Fungsi ini menghitung hasil ekspresi menggunakan konsep postorder, yaitu menghitung bagian kiri dan kanan terlebih dahulu, lalu operatornya.

D. Binary Search Tree

Pengertian Binary Search Tree

Binary Search Tree atau BST adalah binary tree yang memiliki aturan khusus.

Aturannya adalah:

  1. Nilai yang lebih kecil dari root disimpan di sebelah kiri.
  2. Nilai yang lebih besar dari root disimpan di sebelah kanan.
  3. Aturan tersebut berlaku juga untuk setiap subtree.

Contoh BST:

        5
      /   \
     2     30
      \   /  \
       4 25   40

BST memudahkan proses pencarian karena setiap perbandingan dapat mengurangi area pencarian.

Kode
# Implementasi Binary Search Tree

class BSTNode:
    def __init__(self, key):
        self.key = key
        self.left = None
        self.right = None


def insert(root, key):
    if root == None:
        print("Masukkan", key, "sebagai node baru")
        return BSTNode(key)

    if key < root.key:
        print(key, "lebih kecil dari", root.key, "-> masuk ke kiri")
        root.left = insert(root.left, key)
    elif key > root.key:
        print(key, "lebih besar dari", root.key, "-> masuk ke kanan")
        root.right = insert(root.right, key)
    else:
        print(key, "sudah ada di dalam BST")

    return root


def search(root, key):
    if root == None:
        return False

    print("Cek node:", root.key)

    if key == root.key:
        return True
    elif key < root.key:
        return search(root.left, key)
    else:
        return search(root.right, key)


def inorderBST(root):
    if root != None:
        inorderBST(root.left)
        print(root.key, end=' ')
        inorderBST(root.right)

Penjelasan Insert dan Search pada BST

Pada proses insert, program membandingkan data baru dengan node yang sedang diperiksa.

  • Jika data baru lebih kecil, maka data diarahkan ke subtree kiri.
  • Jika data baru lebih besar, maka data diarahkan ke subtree kanan.
  • Jika data sama, maka data tidak ditambahkan lagi agar tidak terjadi duplikasi.

Pada proses search, cara kerjanya hampir sama dengan insert.

Contoh jika mencari 25:

  1. Mulai dari root 5.
  2. Karena 25 > 5, pindah ke kanan.
  3. Cek node 30.
  4. Karena 25 < 30, pindah ke kiri.
  5. Data 25 ditemukan.

Hasil inorder traversal pada BST akan menampilkan data secara terurut dari kecil ke besar.

F. Delete Node pada BST

Pengertian Delete pada BST

Delete node pada BST memiliki beberapa kemungkinan kondisi.

  1. Node tidak memiliki child
    Node langsung dihapus.

  2. Node memiliki satu child
    Node digantikan oleh child yang dimilikinya.

  3. Node memiliki dua child
    Node digantikan oleh nilai terkecil dari subtree kanan atau nilai terbesar dari subtree kiri.

Pada contoh ini, pengganti yang digunakan adalah nilai terkecil dari subtree kanan.

Kode
# Delete node pada BST

def minValueNode(node):
    current = node
    while current.left != None:
        current = current.left
    return current


def deleteNode(root, key):
    if root == None:
        return root

    if key < root.key:
        print(key, "lebih kecil dari", root.key, "-> cari ke kiri")
        root.left = deleteNode(root.left, key)

    elif key > root.key:
        print(key, "lebih besar dari", root.key, "-> cari ke kanan")
        root.right = deleteNode(root.right, key)

    else:
        print("Node", key, "ditemukan dan akan dihapus")

        if root.left == None:
            return root.right
        elif root.right == None:
            return root.left

        pengganti = minValueNode(root.right)
        print("Pengganti node", key, "adalah", pengganti.key)
        root.key = pengganti.key
        root.right = deleteNode(root.right, pengganti.key)

    return root


print("Data sebelum delete:")
inorderBST(root)
print()

print("\nDelete node 2")
root = deleteNode(root, 2)

print("\nData setelah delete:")
inorderBST(root)
print()

Penjelasan Delete Node

Pada contoh kode, node 2 dihapus dari BST.

Sebelum menghapus, program mencari posisi node tersebut dengan aturan BST:

  • Jika nilai yang dicari lebih kecil dari node saat ini, program bergerak ke kiri.
  • Jika nilai yang dicari lebih besar dari node saat ini, program bergerak ke kanan.
  • Jika nilai sama, node ditemukan.

Setelah node ditemukan, program mengecek kondisi child dari node tersebut. Jika node hanya memiliki satu child, maka child tersebut dapat langsung menggantikan node yang dihapus.

G. Perbandingan Tree, Binary Tree, dan BST

Jenis Penjelasan Aturan Utama
Tree Struktur data hierarki yang terdiri dari node dan edge Memiliki root dan hubungan parent-child
Binary Tree Tree yang setiap node maksimal memiliki dua child Child dibagi menjadi kiri dan kanan
Binary Search Tree Binary tree yang datanya disusun agar mudah dicari Kiri lebih kecil, kanan lebih besar

Kesimpulannya, BST adalah bentuk khusus dari binary tree, sedangkan binary tree adalah bentuk khusus dari tree.

H. Kesimpulan

Tree adalah struktur data non-linear yang digunakan untuk menggambarkan hubungan hierarki. Tree terdiri dari node, edge, root, parent, child, leaf, level, dan height.

Binary Tree adalah tree yang setiap node-nya memiliki maksimal dua child. Pada Binary Tree, traversal dapat dilakukan dengan preorder, inorder, dan postorder.

Parse Tree digunakan untuk menggambarkan struktur ekspresi matematika. Dengan parse tree, program dapat mengevaluasi ekspresi menggunakan traversal.

Binary Search Tree adalah binary tree yang memiliki aturan nilai kecil berada di kiri dan nilai besar berada di kanan. Aturan ini membuat proses insert, search, dan delete menjadi lebih terstruktur.
