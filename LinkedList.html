7.1 Linked List

Linked List adalah struktur data linear yang menyimpan data dalam bentuk rangkaian node. Setiap node menyimpan data dan alamat/pointer menuju node berikutnya.

Pada catatan ini, materi yang dibahas meliputi:

  1. Pengertian linked list
  2. Struktur node
  3. Perbedaan linked list dan array
  4. Singly linked list
  5. Operasi dasar: isEmpty, add, show, size, search, dan remove
  6. Doubly linked list
  7. Kelebihan, kekurangan, dan kompleksitas linked list

Pengertian Linked List

Linked List adalah kumpulan data yang saling terhubung menggunakan pointer atau referensi. Berbeda dengan array, data pada linked list tidak harus disimpan di alamat memori yang berurutan.

Setiap elemen pada linked list disebut node. Sebuah node biasanya memiliki dua bagian utama:

  1. Data: nilai yang disimpan di dalam node.
  2. Next: pointer atau referensi menuju node berikutnya.

Bentuk sederhananya:

Head -> 31 -> 77 -> 17 -> None

Keterangan:

  • Head adalah penanda node pertama.
  • 31, 77, dan 17 adalah data yang tersimpan.
  • None menandakan akhir linked list.

Struktur Node

Node adalah bagian paling dasar dalam linked list. Tanpa node, linked list tidak dapat terbentuk.

Struktur node pada singly linked list:

+------+------+
| data | next |
+------+------+

Contoh:

+------+------+
|  31  | next | ---> node berikutnya
+------+------+

Jika sebuah node berada di akhir list, maka bagian next bernilai None.

Kode
# Membuat class Node untuk singly linked list

class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

    def getData(self):
        return self.data

    def getNext(self):
        return self.next

    def setData(self, newdata):
        self.data = newdata

    def setNext(self, newnext):
        self.next = newnext

Penjelasan Class Node

class Node:

Bagian ini digunakan untuk membuat cetakan node.

self.data = data

Digunakan untuk menyimpan nilai yang ada di dalam node.

self.next = None

Digunakan untuk menyimpan alamat node berikutnya. Pada awal pembuatan node, nilai next diisi None karena node belum terhubung dengan node lain.

Method getData, getNext, setData, dan setNext digunakan untuk mengambil atau mengubah isi node.

Perbedaan Linked List dan Array

Aspek Linked List Array/List Biasa
Letak data Tidak harus berurutan di memori Umumnya tersimpan berurutan
Akses data Dilakukan secara berurutan dari head Bisa langsung memakai indeks
Insert/delete Lebih fleksibel karena cukup mengatur pointer Bisa lebih berat karena perlu menggeser data
Kebutuhan tambahan Membutuhkan pointer/referensi Tidak membutuhkan pointer tambahan per elemen

Linked list cocok digunakan ketika data sering ditambah atau dihapus. Namun, jika data sering diakses menggunakan indeks tertentu, array/list biasa biasanya lebih sederhana digunakan.

A. Singly Linked List

Singly Linked List adalah linked list yang setiap node hanya memiliki satu pointer, yaitu pointer next menuju node berikutnya.

Arah hubungannya hanya satu arah:

Head -> 31 -> 77 -> 17 -> None

Karena arahnya satu arah, proses penelusuran data dimulai dari head lalu bergerak ke node berikutnya sampai bertemu None.

Membuat Class UnorderedList

Pada contoh ini, linked list dibuat dalam bentuk UnorderedList, yaitu list yang datanya tidak harus berurutan.

Saat linked list masih kosong, head bernilai None.

Head -> None
Kode
# Class dasar UnorderedList

class UnorderedList:
    def __init__(self):
        self.head = None

    def isEmpty(self):
        return self.head == None

    def show(self):
        current = self.head
        print("Head ->", end=" ")

        while current != None:
            print(current.getData(), end=" -> ")
            current = current.getNext()

        print("None")

Penjelasan head, isEmpty, dan show

self.head = None

Digunakan untuk menandai bahwa linked list masih kosong.

return self.head == None

Digunakan untuk mengecek apakah list kosong atau tidak.

current = self.head

Variabel current digunakan untuk melakukan traversal atau penelusuran node dari awal sampai akhir.

while current != None:

Perulangan berjalan selama node yang sedang dicek belum mencapai akhir linked list.

Operasi Add pada Linked List

Operasi add digunakan untuk menambahkan node baru. Pada contoh ini, data baru dimasukkan di bagian depan list, tepat setelah Head.

Misalnya list awal:

Head -> None

Setelah add(31):

Head -> 31 -> None

Setelah add(77):

Head -> 77 -> 31 -> None

Data baru menjadi node pertama karena head dipindahkan ke node baru.

Kode
# Menambahkan method add ke dalam class UnorderedList

class UnorderedList:
    def __init__(self):
        self.head = None

    def isEmpty(self):
        return self.head == None

    def show(self):
        current = self.head
        print("Head ->", end=" ")

        while current != None:
            print(current.getData(), end=" -> ")
            current = current.getNext()

        print("None")

    def add(self, item):
        temp = Node(item)
        temp.setNext(self.head)
        self.head = temp

Penjelasan Operasi Add

temp = Node(item)

Membuat node baru yang berisi data item.

temp.setNext(self.head)

Node baru diarahkan ke node yang sebelumnya menjadi head.

self.head = temp

head dipindahkan ke node baru. Dengan cara ini, data baru selalu masuk dari depan linked list.

Traversal pada Linked List

Traversal adalah proses menelusuri node satu per satu dari head sampai None.

Traversal digunakan pada banyak operasi, misalnya:

  1. Menampilkan isi linked list
  2. Menghitung jumlah node
  3. Mencari data
  4. Menghapus data tertentu

Contoh alur traversal:

Head -> 17 -> 77 -> 31 -> None
        ↑
     current

Setelah satu langkah:

Head -> 17 -> 77 -> 31 -> None
              ↑
           current

Operasi Size

Operasi size digunakan untuk menghitung jumlah node dalam linked list.

Cara kerjanya:

  1. Mulai dari head.
  2. Siapkan variabel count = 0.
  3. Selama node belum None, tambahkan count.
  4. Geser current ke node berikutnya.
  5. Jika sudah sampai None, kembalikan nilai count.
Kode
# Menambahkan method size

class UnorderedList:
    def __init__(self):
        self.head = None

    def isEmpty(self):
        return self.head == None

    def show(self):
        current = self.head
        print("Head ->", end=" ")

        while current != None:
            print(current.getData(), end=" -> ")
            current = current.getNext()

        print("None")

    def add(self, item):
        temp = Node(item)
        temp.setNext(self.head)
        self.head = temp

    def size(self):
        current = self.head
        count = 0

        while current != None:
            count = count + 1
            current = current.getNext()

        return count
Kode
# Contoh penggunaan size

mylist = UnorderedList()
mylist.add(31)
mylist.add(77)
mylist.add(17)
mylist.add(93)

mylist.show()
print("Jumlah node:", mylist.size())

Jumlah node: 4

Operasi Search

Operasi search digunakan untuk mencari apakah suatu data ada di dalam linked list.

Cara kerjanya:

  1. Mulai dari head.
  2. Siapkan variabel found = False.
  3. Bandingkan data pada node saat ini dengan data yang dicari.
  4. Jika sama, ubah found menjadi True.
  5. Jika tidak sama, lanjut ke node berikutnya.
  6. Jika sampai akhir tidak ditemukan, hasilnya tetap False.
Kode
# Menambahkan method search

class UnorderedList:
    def __init__(self):
        self.head = None

    def isEmpty(self):
        return self.head == None

    def show(self):
        current = self.head
        print("Head ->", end=" ")

        while current != None:
            print(current.getData(), end=" -> ")
            current = current.getNext()

        print("None")

    def add(self, item):
        temp = Node(item)
        temp.setNext(self.head)
        self.head = temp

    def size(self):
        current = self.head
        count = 0

        while current != None:
            count = count + 1
            current = current.getNext()

        return count

    def search(self, item):
        current = self.head
        found = False
        looping = 0

        while current != None and not found:
            looping = looping + 1
            print("Looping ke-", looping)
            print("Data yang dicek:", current.getData())

            if current.getData() == item:
                found = True
                print("Status: data ditemukan")
            else:
                current = current.getNext()
                print("Status: data belum ditemukan")

            print()

        return found

Operasi Remove

Operasi remove digunakan untuk menghapus node yang berisi data tertentu.

Pada operasi ini, diperlukan dua pointer:

  1. current: node yang sedang diperiksa.
  2. previous: node sebelum current.

Jika data ditemukan, hubungan pointer akan diubah agar node yang dihapus tidak lagi dilewati.

Contoh:

Head -> 93 -> 17 -> 77 -> 31 -> None

Jika data 77 dihapus:

Head -> 93 -> 17 -> 31 -> None

Node 17 langsung diarahkan ke node 31.

Kode
# Class UnorderedList lengkap dengan remove

class UnorderedList:
    def __init__(self):
        self.head = None

    def isEmpty(self):
        return self.head == None

    def show(self):
        current = self.head
        print("Head ->", end=" ")

        while current != None:
            print(current.getData(), end=" -> ")
            current = current.getNext()

        print("None")

    def add(self, item):
        temp = Node(item)
        temp.setNext(self.head)
        self.head = temp

    def size(self):
        current = self.head
        count = 0

        while current != None:
            count = count + 1
            current = current.getNext()

        return count

    def search(self, item):
        current = self.head
        found = False

        while current != None and not found:
            if current.getData() == item:
                found = True
            else:
                current = current.getNext()

        return found

    def remove(self, item):
        current = self.head
        previous = None
        found = False

        while current != None and not found:
            if current.getData() == item:
                found = True
            else:
                previous = current
                current = current.getNext()

        if found == False:
            print("Data", item, "tidak ada di dalam list")
        elif previous == None:
            self.head = current.getNext()
            print("Data", item, "berhasil dihapus dari head")
        else:
            previous.setNext(current.getNext())
            print("Data", item, "berhasil dihapus")

Penjelasan Remove

previous = None

Pada awal pencarian, belum ada node sebelum head, sehingga previous bernilai None.

previous = current
current = current.getNext()

Jika data belum ditemukan, previous digeser ke node saat ini, lalu current digeser ke node berikutnya.

self.head = current.getNext()

Digunakan jika data yang dihapus berada pada node pertama.

previous.setNext(current.getNext())

Digunakan jika data yang dihapus berada di tengah atau akhir linked list. Pointer dari node sebelumnya langsung diarahkan ke node setelah node yang dihapus.

B. Doubly Linked List

Doubly Linked List adalah linked list yang setiap node memiliki dua pointer:

  1. next: menuju node berikutnya.
  2. prev: menuju node sebelumnya.

Bentuknya:

None <- Head -> 100 <-> 10 <-> 15 -> None

Doubly linked list lebih fleksibel karena dapat ditelusuri dari dua arah, tetapi setiap node membutuhkan satu pointer tambahan.

Kode
# Membuat node untuk doubly linked list

class DoubleNode:
    def __init__(self, data):
        self.data = data
        self.next = None
        self.prev = None

    def getData(self):
        return self.data

    def getNext(self):
        return self.next

    def getPrev(self):
        return self.prev

    def setData(self, newdata):
        self.data = newdata

    def setNext(self, newnext):
        self.next = newnext

    def setPrev(self, newprev):
        self.prev = newprev

Add pada Doubly Linked List

Pada doubly linked list, saat menambahkan node di depan, ada dua hubungan pointer yang perlu diperhatikan:

  1. Node baru mengarah ke head lama melalui next.
  2. Jika head lama tidak kosong, maka prev dari head lama harus mengarah ke node baru.

Alurnya:

Node baru -> head lama
head lama.prev -> node baru
head -> node baru
Kode
# Class DoublyLinkedList

class DoublyLinkedList:
    def __init__(self):
        self.head = None

    def isEmpty(self):
        return self.head == None

    def show(self):
        current = self.head
        print("None <- Head ->", end=" ")

        while current != None:
            if current.getNext() == None:
                print(current.getData(), end=" -> ")
            else:
                print(current.getData(), end=" <-> ")
            current = current.getNext()

        print("None")

    def add(self, item):
        temp = DoubleNode(item)
        temp.setNext(self.head)
        temp.setPrev(None)

        if self.head != None:
            self.head.setPrev(temp)

        self.head = temp

    def size(self):
        current = self.head
        count = 0

        while current != None:
            count = count + 1
            current = current.getNext()

        return count

    def search(self, item):
        current = self.head
        found = False

        while current != None and not found:
            if current.getData() == item:
                found = True
            else:
                current = current.getNext()

        return found

    def remove(self, item):
        current = self.head
        found = False

        while current != None and not found:
            if current.getData() == item:
                found = True
            else:
                current = current.getNext()

        if found == False:
            print("Data", item, "tidak ada di dalam list")
            return

        previous_node = current.getPrev()
        next_node = current.getNext()

        if previous_node == None:
            self.head = next_node
        else:
            previous_node.setNext(next_node)

        if next_node != None:
            next_node.setPrev(previous_node)

        print("Data", item, "berhasil dihapus")

Perbedaan Singly dan Doubly Linked List

Aspek Singly Linked List Doubly Linked List
Pointer Hanya next Memiliki next dan prev
Arah traversal Satu arah Dua arah
Penggunaan memori Lebih hemat Lebih besar karena ada prev
Penghapusan node Perlu bantuan node sebelumnya Lebih mudah karena ada prev
Struktur Lebih sederhana Lebih kompleks

Singly linked list cocok untuk materi dasar karena strukturnya lebih sederhana. Doubly linked list cocok ketika program membutuhkan akses maju dan mundur antar node.

C. Kompleksitas Linked List

Operasi Kompleksitas Keterangan
Menambah di depan O(1) Cukup mengubah head
Menampilkan semua data O(n) Harus traversal semua node
Menghitung jumlah node O(n) Harus mengecek dari awal sampai akhir
Mencari data O(n) Data dicek satu per satu
Menghapus data tertentu O(n) Perlu mencari data terlebih dahulu

Keterangan:

  • O(1) berarti waktu proses tetap, tidak bergantung jumlah data.
  • O(n) berarti waktu proses dapat bertambah sesuai jumlah node.

D. Kelebihan dan Kekurangan Linked List

Kelebihan

  1. Ukuran data lebih fleksibel karena node dapat ditambah atau dihapus.
  2. Insert dan delete lebih mudah dilakukan, terutama di bagian depan.
  3. Tidak harus menyimpan data secara berurutan di memori.
  4. Cocok untuk membuat struktur data lain seperti stack dan queue.

Kekurangan

  1. Tidak bisa mengakses data langsung menggunakan indeks seperti array.
  2. Pencarian data membutuhkan traversal dari head.
  3. Membutuhkan memori tambahan untuk pointer.
  4. Kode implementasinya lebih panjang dibanding list biasa.

Kesimpulan

Linked list adalah struktur data linear yang terdiri dari beberapa node yang saling terhubung. Setiap node menyimpan data dan pointer ke node berikutnya. Pada singly linked list, node hanya memiliki pointer next, sedangkan pada doubly linked list node memiliki pointer next dan prev.

Operasi dasar linked list meliputi menambah data, menampilkan data, menghitung jumlah node, mencari data, dan menghapus data. Linked list sangat berguna ketika data sering berubah, tetapi kurang cocok jika data harus sering diakses langsung berdasarkan indeks.
